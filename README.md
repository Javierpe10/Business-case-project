# Digital Opportunity Analysis for Local Businesses

## Overview
This project analyzes local businesses in Madrid to identify digital business opportunities.

## Objective
Identify high-reputation businesses without websites and evaluate the potential for digital services.

## Tools
- Tableau
- Python
- Statistical analysis

## Key Findings
- Businesses with websites accumulate significantly more reviews.
- Several high-reputation businesses lack digital presence.
- These businesses represent potential clients for digital services.

## Dashboard
The Tableau dashboard highlights businesses with the highest opportunity score.
